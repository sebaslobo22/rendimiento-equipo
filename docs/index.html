Cómo trabaja

Mide antes de cambiar.

Cuatro scripts de Python sin dependencias y una consulta en Swift. El agente los corre en este orden.

  1. Diagnosticar diagnosticar.py

    Consulta el hardware en el momento: niveles de CPU, presión de memoria, Metal, codificadores, Neural Engine y temperatura.

  2. Recomendar perfil.py

    Cruza el diagnóstico con lo medido y entrega comandos, frenos y un bloque para cada subagente, que no hereda skills ni contexto.

  3. Medir medir.py

    Compara el método nuevo con el actual. Solo adopta un ganador claro: 15 % mejor como mínimo y diferencia visual menor a 2 de 255.

  4. Limpiar limpiar.py

    Muestra los procesos que dejaron los agentes y, con --aplicar, los apaga por PID. Los protegidos no se tocan.

Reglas

Las que más se rompen.

Seis de las doce que el agente lee primero. Cada una viene de un error medido o de la documentación oficial.

Consulta el hardware, nunca lo escribas a mano.

Otro chip trae otros núcleos, niveles y nombres. La skill pregunta a sysctl, Metal, VideoToolbox y Core ML cada vez.

memory_pressure va sin argumentos.

Con -l o -p aplica presión real al equipo y altera lo que querías medir.

Con hardware, bitrate fijo.

En Remotion, --crf desactiva el hardware sin avisar. Sin bitrate, un video de 52 s salió con 93 MB contra 67 MB en la CPU.

Un solo servidor de Whisper.

Atiende una petición a la vez. Un segundo servidor no suma velocidad y carga otra copia del modelo en memoria.

Caché de video por render.

Remotion reserva por defecto la mitad de la memoria disponible en cada render. Con tres a la vez se pasa de la RAM.

Cada agente apaga lo suyo.

Por PID y solo lo que lanzó. El servidor de dictado de OpenWhispr y los procesos en uso quedan fuera siempre.

Instalar

Tres comandos y listo.

El instalador enlaza la skill donde la buscan Claude Code y Codex. No copia archivos, no instala dependencias y no usa la red.

git clone https://github.com/sebaslobo22/rendimiento-equipo.git ~/rendimiento-equipocd ~/rendimiento-equipo./install.sh
python3 ~/rendimiento-equipo/skills/rendimiento-equipo/scripts/perfil.py --formato texto
cd ~/rendimiento-equipo && git pull
~/rendimiento-equipo/install.sh --desinstalar

Queda enlazada en ~/.claude/skills/ y ~/.agents/skills/. Abre una sesión nueva y pide un render o una transcripción: la skill se activa sola.
